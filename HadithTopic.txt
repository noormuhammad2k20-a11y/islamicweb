## 3. CONTROLLER: `app/Http/Controllers/HadithController.php`

Create this controller:

```php
<?php
namespace App\Http\Controllers;

use App\Models\HadithTopic;
use App\Models\Hadith;

class HadithController extends Controller
{
    // Hub page — shows all topics as cards
    public function index()
    {
        $topics = HadithTopic::withCount('hadiths')->orderBy('topic_name')->get();
        return view('hadith.index', compact('topics'));
    }

    // Topic detail page — shows all hadiths for a topic
    public function show(HadithTopic $topic)
    {
        $hadiths = $topic->hadiths()->orderBy('id')->paginate(10);
        $otherTopics = HadithTopic::where('id', '!=', $topic->id)
                        ->inRandomOrder()->limit(6)->get();
        return view('hadith.show', compact('topic', 'hadiths', 'otherTopics'));
    }
}
```

## 4. MODELS

### `app/Models/HadithTopic.php`
```php
<?php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class HadithTopic extends Model
{
    protected $table = 'hadith_topics';
    
    public function hadiths()
    {
        return $this->hasMany(Hadith::class, 'topic_id');
    }
}
```

### `app/Models/Hadith.php`
```php
<?php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Hadith extends Model
{
    protected $table = 'hadiths';
    
    public function topic()
    {
        return $this->belongsTo(HadithTopic::class, 'topic_id');
    }
}
```

## 8. CLIENT-SIDE SEARCH (for the hub page)

Add this vanilla JavaScript to the hub page for live topic filtering:

```javascript
document.getElementById('topicSearch').addEventListener('input', function() {
    const query = this.value.toLowerCase();
    document.querySelectorAll('.topic-card-wrapper').forEach(card => {
        const name = card.querySelector('.topic-name').textContent.toLowerCase();
        card.style.display = name.includes(query) ? 'block' : 'none';
    });
});
```
