## PROMPT – Eliminate Duplicate Content Across All Islamic Events Pages (STRICT)

The current implementation is using the exact same introduction on every `/islamic-events/{month}` page and only replacing the month name (e.g., Muharram, Safar, Rajab, Sha'ban, Ramadan). This is **not acceptable** because it creates duplicate content, weakens topical authority, and negatively impacts SEO.

### STRICT REQUIREMENTS

For every Islamic month page, generate **100% unique, month-specific content**.

Do **NOT** use the same paragraphs with only the month name replaced.

Do **NOT** use generic introductions such as:

* "The month of {Month} holds profound historical and spiritual significance..."
* "Operating within a completely lunar cycle..."
* "Historically, the designation of Islamic months..."
* "Understanding the chronological context..."
* or any other boilerplate text reused across multiple pages.

These generic paragraphs must be completely removed.

# Every Month Must Have Its Own Identity

Each page should immediately explain **why this specific month is unique**, instead of explaining the Hijri calendar in general.

The introduction must focus only on that month's:

* historical importance
* religious importance
* Quranic relevance (if applicable)
* authentic Hadith
* famous events
* worship associated with the month
* Islamic rulings
* virtues
* lessons
* notable personalities
* historical milestones
