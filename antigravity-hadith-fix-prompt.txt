PROBLEM 1: All arabic_text values are placeholder strings
------------------------------------------------------------

Every row in the hadiths table has:
  arabic_text = '... (placeholder until arabic fetch)'

This needs to be replaced with REAL Arabic hadith text.

THE FIX — Create ONE Laravel Artisan command:

FILE: app/Console/Commands/FetchHadithArabicText.php

Logic:
- Use the FREE public API at: https://cdn.jsdelivr.net/gh/fawazahmed0/hadith-api@1/editions/ara-bukhari/{hadith_number}.json
  (This returns Arabic text for Sahih Bukhari hadiths by number)
- For Sahih Bukhari hadiths (collection_id = 1):
  - The hadiths table has a column called 'reference' like "Sahih Bukhari 52" 
  - Extract the number from reference using: preg_match('/\d+$/', $hadith->reference, $matches)
  - Use that number to call the API: https://cdn.jsdelivr.net/gh/fawazahmed0/hadith-api@1/editions/ara-bukhari/{number}.json
  - The JSON response has structure: { "hadiths": [{ "text": "Arabic text here..." }] }
  - OR try alternate: https://cdn.jsdelivr.net/gh/fawazahmed0/hadith-api@1/editions/ara-bukhari.min.json
    (full collection JSON with all hadiths indexed by number)

IMPORTANT: Many hadiths may not have a clean number (hadith_number column is NULL in many rows).
So parse the number from the 'reference' column string. Example:
  "Sahih Bukhari 52" → extract 52
  "Sahih Bukhari 172" → extract 172

Command behavior:
1. Load the FULL Sahih Bukhari Arabic collection from the CDN URL in one API call (more efficient):
   URL: https://cdn.jsdelivr.net/gh/fawazahmed0/hadith-api@1/editions/ara-bukhari.min.json
   This returns a big JSON: { "hadiths": { "1": {"text": "..."}, "2": {"text": "..."}, ... } }

2. For each hadith in DB where arabic_text LIKE '%placeholder%' AND collection_id = 1:
   - Extract number from reference string
   - Look up that number in the loaded JSON
   - If found, UPDATE hadiths SET arabic_text = [fetched_arabic] WHERE id = X

3. For hadiths with collection_id != 1 (other collections like Muslim, Abu Dawud):
   - Use appropriate CDN URLs:
     Sahih Muslim: https://cdn.jsdelivr.net/gh/fawazahmed0/hadith-api@1/editions/ara-muslim.min.json
     Abu Dawud: https://cdn.jsdelivr.net/gh/fawazahmed0/hadith-api@1/editions/ara-abudawud.min.json
   - Same extraction logic

4. Add --dry-run flag to test without DB writes
5. Add progress output with $this->info() and $this->progressBar()
6. Add --batch=50 option to process in chunks to avoid memory issues
7. Log failures to storage/logs/arabic_fetch.log

Command signature: hadith:fetch-arabic {--dry-run} {--batch=100} {--collection=all}

Register in app/Console/Kernel.php

Also create a simpler DB seeder alternative in case the API is unavailable:
FILE: database/seeders/HadithArabicTextSeeder.php
